# Smart Grid Energy Analytics: Electricity Consumption Analysis & Anomaly Detection

## Project Overview
This project focuses on analysing household electricity consumption data to identify consumption patterns and detect unusual electricity usage using Machine Learning techniques.

## Objectives
- Analyse household electricity consumption patterns.
- Perform exploratory data analysis (EDA).
- Identify hourly, daily and weekly consumption trends.
- Detect abnormal consumption patterns using statistical methods and Isolation Forest.


## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Techniques
- Statistical Thresholding (3-Sigma Method)
- Isolation Forest
- StandardScaler

## Project Workflow
1. Data Loading and Understanding
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Anomaly Detection
6. Visualisation and Interpretation

## Key Findings
- Analysed more than 2 million household electricity consumption records.
- Explored hourly, daily and weekly consumption patterns.
- Identified unusual electricity consumption patterns using Isolation Forest.
